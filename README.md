# Emerald City Estates

An original offline property-trading board game on real greater Seattle streets: buy, build homes and towers, trade and outlast 1-5 computer players.

**Play:** https://g-zack-nguyen.github.io/emerald-city-estates/

It plays in any current browser (Safari, Chrome, Firefox or Edge), on a phone in portrait or on a computer.

## Play offline

Open the link once while you are online. After that Emerald City Estates plays offline too, in the same browser. When a new
version is out, the game says "New version ready"; tap Update now when you like.

## On an iPhone or iPad: add it to the Home Screen

1. Open the link above in Safari.
2. Tap Share, then **Add to Home Screen**.
3. Start Emerald City Estates from the Home Screen.

Add it before you play, and play from there: the Home Screen app keeps its own save, apart from the Safari tab’s,
and Safari can remove a tab’s save after 7 days without a visit. To move a save, use Settings > Copy save code in
one and Settings > Import save code in the other.

On Android: Chrome menu > Install app. On a computer: the Install button in the address bar (Chrome, Edge), or
File > Add to Dock (Safari on a Mac).

## Privacy

No account, no ads, no tracking. The game sends nothing anywhere: your progress is saved on your device only.
